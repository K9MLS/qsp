    1. Your area

    —

    These are the same codes SkywarnPlus and other alert tools use. A county code has a C in the middle, such as TXC121 for Denton County, Texas; a forecast zone code has a Z, such as TXZ103. NWS issues most warnings by county and most watches and advisories by zone, so give both for your area. To find yours, open alerts.weather.gov, choose your state, and look under By County/Zone; or see the NWS public zone list. A county code also catches alerts NWS issues by zone for that county, so if you give only one, give the county. Check codes asks NWS about each one and shows the name it has for it, so a mistyped code shows up here rather than as quiet weather.

    Add your county code too. Tornado, severe thunderstorm and flash flood warnings are issued by county, so with only forecast-zone codes they would be missed. A county code has a C in the middle, such as TXC121.

      2. Which alerts

      —

      Every warning and Every watch cover whatever NWS calls them: a Flood Watch and a Winter Storm Warning as much as a Tornado Warning. Tick single kinds instead if you want fewer. Tests and exercises NWS sends are never used, whatever is ticked. Each alert is sent once, and again only if NWS makes it last longer; the reissues that follow a storm as it moves are not sent. When you switch alerts on, or tick another kind or add a county, what is already in effect goes out within a minute. Only a restart of QSP is silent, so an upgrade never repeats what was sent before it.

      3. Where alerts go

      An alert goes out as a group text, the same kind the This server page sends, to this server's own hotspots and Motorola repeaters on the talkgroup — but never to linked servers or bridged networks, because weather is local. A radio shows it from the ID below, so choose one that no radio of yours uses; a radio does not show a text from its own ID. Alerts go out at least fifteen seconds apart and at most six in ten minutes, warnings first; in a busy storm the rest wait their turn rather than being dropped, unless they expire first.

      Sends one text reading “QSP WEATHER TEST: this is only a test” on the saved talkgroup, from the saved ID, to this server's stations. Save first if you have changed them.

      4. Your contact email

      The National Weather Service asks every program that reads its alerts to say who runs it, and refuses ones that do not. QSP sends this address with each request and nowhere else.

      What QSP sees

      —

      Every alert NWS has for your area right now, and what QSP decided about it. The text beside each is exactly what a radio shows. Sent alerts say when; held and waiting ones say why. In Preview, nothing here has been transmitted.
