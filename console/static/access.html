    Talkgroups

    —

    A talkgroup is a channel members share. Allow everything except with an empty list carries every talkgroup, which is what a new instance does and is fine for a club. Allow only refuses anything not listed, which is what you want facing the internet. Ranges work: 3100-3199.

    Which talkgroups this instance carries, per timeslot. Most traffic is on timeslot 2.

    Who may connect

    Registration is checked when a hotspot logs in, before its password, so a refused ID never reaches the credential path. Subscribers are checked on every transmission — a refused radio is silenced without disconnecting the hotspot carrying it, so one member cannot knock another off the network.

    Registration is checked when a hotspot or repeater logs in. Subscribers are checked on every transmission, so a refused radio does not disconnect the hotspot carrying it.

    Motorola repeaters

    IP Site Connect has no password. A repeater is admitted by its radio ID alone, so this list is the only thing standing between the port and anybody who knows one. Talkgroup and subscriber rules above apply to these repeaters too.

    A member's own password

    One shared password means removing a member requires a new one and every other member reconfiguring their hotspot. Giving a member their own means removing them is deleting it, and nobody else notices. A member without one keeps using the shared password, so this can be done one member at a time. Removing a password stops the next login, not the current session — to put somebody off the network now, add their ID to the list above.

    Issue or remove one member's password. The rest of the network is unaffected either way.
