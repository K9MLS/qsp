  1. Open your hotspot

    In a browser, go to your hotspot's dashboard — usually pi-star.local or wpsd.local — then open Admin → Configuration → DMR Configuration.

    Will this hotspot carry any other DMR network as well?

    Then set every other network on the page to off. Two networks at once compete for the same talkgroup numbers, and yours would reach whichever answered first. You can switch back at any time.

    Leave your other networks alone. Step 3 gives you a block to paste that keeps them all working, by putting this network behind a leading digit of your choosing.

  2. Fill in the custom network

    Set Custom DMR Network Enable to on, then enter these:

    Server Name QSP
    Server Address …
    Port …
    Password Sent to you separately — it is not shown on this page
    ESSID None

    This network admits only hotspots it has listed. Send your hotspot’s DMR ID to whoever runs it first, or it will be turned away however right the rest is.

    Then press Apply Changes. Your hotspot restarts, which takes a few seconds.

  3. Paste this into DMRGateway

    Your hotspot keeps its other networks. This block adds ours behind a leading digit, so dialling 7000009 reaches us and every number you already use still reaches where it always did.

    Open /etc/dmrgateway on your hotspot and check which of these two are still free. Nothing on this page can see that file.

    Text messages

    Texts cross this network exactly as your radio sends them, so whether another radio can read yours depends on the text format set on your radio. Choose M-SMS if your radio offers it.

    Format Which radios can read it
    M-SMS Use this Motorola radios, and most AnyTone, BTech, TYT and Retevis radios. Texts this network sends you are in this format.
    DMR Standard Most AnyTone, BTech, TYT and Retevis radios. Most Motorola radios show nothing.
    H-M Hytera radios. Motorola radios show nothing.
    • The sender's setting is the one that counts. If someone's radio shows nothing when you text it, change the format on yours, not on theirs.
    • If your radio asks for a CAI network, set it to 12. Motorola-format texts are addressed with it and your DMR ID.
    • On a hotspot that carries only this network, turn off any automatic rewrite rules in its dashboard. They can readdress a text so it never arrives. If you pasted the DMRGateway block above, leave those rules as they are.
