  1. Open your hotspot

    In a browser, go to your hotspot's dashboard — usually pi-star.local or wpsd.local — then open Admin → Configuration → DMR Configuration.

    Will this hotspot carry any other DMR network as well?

    Then set every other network on the page to off. Two networks at once compete for the same talkgroup numbers, and yours would reach whichever answered first. You can switch back at any time.

    Leave your other networks alone. Step 3 gives you a block to paste that keeps them all working, by putting this network behind a leading digit of your choosing.

  2. Fill in the custom network

    Set Custom DMR Network Enable to on, then enter these:

    Server Name QSP
    Server Address …
    Port …
    Password Sent to you separately — it is not shown on this page
    ESSID None

    Then press Apply Changes. Your hotspot restarts, which takes a few seconds.

  3. Paste this into DMRGateway

    Your hotspot keeps its other networks. This block adds ours behind a leading digit, so dialling 7000009 reaches us and every number you already use still reaches where it always did.

    Open /etc/dmrgateway on your hotspot and check which of these two are still free. Nothing on this page can see that file.
