  1. Open your hotspot's configuration

    In a browser, go to your hotspot's dashboard — usually http://pi-star.local or http://wpsd.local. Then Admin → Configuration → DMR Configuration.

  2. Turn off your current DMR network

    Set BrandMeister Network Enable to off. Two networks at once compete for the same talkgroups, and yours will reach whichever answers first.

    You can switch back at any time. Nothing here is permanent.

  3. Fill in the custom network

    Set Custom DMR Network Enable to on, then enter these:

    Server Name QSP
    Server Address …
    Port …
    Password Ask whoever runs the network
    ESSID None

    Then press Apply Changes. Your hotspot restarts, which takes a few seconds.

  4. Check it really saved

    Reload the configuration page and confirm the custom network still shows as enabled.

    This step exists because the dashboard has been known to display a network as enabled while the underlying file said otherwise. The hotspot then connects, holds a session, and quietly sends everything to the old network instead. Thirty seconds here saves an evening.
